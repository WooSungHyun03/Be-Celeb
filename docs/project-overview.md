# Project Overview

## 서비스 개요

Be Celeb은 짧은 영상 중심 SNS의 트렌드를 분석하고 사용자 계정 유형에 맞는 콘텐츠 전략을 추천하는 웹서비스입니다.

대상 플랫폼:

- Instagram Reels
- TikTok
- YouTube Shorts

## 핵심 기능

- 현재 유행 중인 콘텐츠 흐름 분석
- 앞으로 유행할 가능성이 높은 트렌드 탐지
- 계정 카테고리별 콘텐츠 아이디어 추천
- AI 기반 분석과 룰베이스 기반 추천 로직의 병행
- 먹방, AI 영상, 댄스, 뷰티, 패션, 일상 등 카테고리별 전략 제공

## MVP 범위

- mock data 기반 페이지 탐색
- Supabase Auth/DB 연결 가능한 client와 SQL 초안
- FastAPI route-service-schema 구조
- OpenAI recommendation API 연결 구조
- Resend test email API 연결 구조
- 데이터/디자인 관리용 JSON 및 문서

## 제외할 기능

- 실제 SNS 데이터 수집
- 실제 추천 알고리즘 완성
- 결제 기능
- 관리자 CRUD 완성 구현
